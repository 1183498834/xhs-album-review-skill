## Anti-template rules (read before generating)

Rednote detects 模板化批量生产 by image features and by an account repeatedly posting near-identical layouts. Two rules:

1. **Tracklist cards must vary per album.** The script supports `--theme auto|dark|light|warm`. With `auto` (default) it samples the dominant color from the album cover and builds the card around it, so every card is naturally different. Do not pass a fixed `dark` theme for every album.
2. **Keep official assets untouched.** The downloaded cover and band photo keep their original pixels and metadata (EXIF) — do not re-encode, resize, or re-save them. Original file fingerprints are a *realness* signal; re-encoding them strips it.

## Run the tracklist card generator

Run the script so the output lands in the same per-album folder as the cover and band photo:

```
python scripts/build_tracklist.py \
  --cover "<artist>-<album-slug>/cover.jpg" \
  --tracks "<artist>-<album-slug>/tracks.json" \
  --out "<artist>-<album-slug>/tracklist.jpg" \
  --artist "<artist>" \
  --album "<album title>" \
  --year <yyyy>
```

Defaults to `--theme auto`. The script produces a 1080×1440 (3:4) card: background sampled from the cover (or one of the named themes), centered cover thumbnail, two columns when ≥6 tracks, with per-track duration. For albums whose cover is dark, `auto` lightens the sampled color so text stays readable.
