# Step 2 — Build the 3 images

| # | Image                | Source                                       |
| - | -------------------- | -------------------------------------------- |
| 1 | Official album cover | Apple Music CDN, 1200×1200 (downloaded in Step 1) |
| 2 | Band / press photo   | `image_search` result, downloaded in Step 1  |
| 3 | Tracklist card        | Generated by `scripts/build_tracklist.py`    |

## Run the tracklist card generator

Run the script so the output lands in the same per-album folder as the cover and band photo:

```
python scripts/build_tracklist.py \
  --cover "<artist>-<album-slug>/cover.jpg" \
  --tracks "<artist>-<album-slug>/tracks.json" \
  --out "<artist>-<album-slug>/tracklist.jpg" \
  --artist "<artist>" \
  --album "<album title>" \
  --year <yyyy>
```

The script produces a 1080×1440 (3:4) card: dark navy background, centered cover thumbnail, two columns when ≥6 tracks, with per-track duration.

## Output of this step

Three files ready to upload in Step 4, all in `<artist>-<album-slug>/`:

1. `cover.jpg`
2. `band-photo.jpg`
3. `tracklist.jpg`
